# 66. Cloud Hands - 2

Historical image study. Modern teaching may differ as the art evolves. Names and numbers are preserved from [moves.md](../../moves.md); notes are editorial observations and interpretations, not a reconstruction of every historical instruction.

## Identification

**shared-series** — Same representative panel as moves 65 and 67.

## Position

The rounded arms exchange upper and lower positions while the stance moves sideways.

## Transition

The montage uses one representative image for each three-entry series; it does not depict all three cycles.

Preceded by: Cloud Hands - 1. Followed by: Cloud Hands - 3.

## Application study — interpretation

Study alternating contact and redirection while changing the base sideways.

## Breathing and attention — editorial suggestions

Breathing and attention are editorial practice suggestions, not recovered instructions for this particular photograph. Allow an easy, unforced breath; do not impose a fixed inhalation or exhalation on each numbered movement.

Attend to the moment one foot becomes free to move.

## Name and context

The cloud image is a movement metaphor. A still records a phase, not the complete repeated pattern.
